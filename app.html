    公開地圖備援順序（不需金鑰，依序嘗試）：
    
        
      
          
    1. 景點與餐廳：Overpass（德國主站 → kumi.systems → private.coffee → mail.ru）→ Nominatim → Photon
      2. 
          
    2. 路線時間：Valhalla → OSRM（openstreetmap.de）→ OSRM 示範站 → 距離估算
      3. 
          
    3. 地名查詢：Nominatim → Photon → BigDataCloud
      4. 
          
    4. 底圖：OpenStreetMap → CARTO → OSM 法國 → OpenTopoMap
      5. 
        
    
        
    Google 金鑰：在 Google Cloud 啟用 Places API (New)、Routes API、Maps JavaScript API。若金鑰設了「HTTP 參照網址」限制，請用 python3 -m http.server 從 http://localhost:8000 開啟並加入允許清單。
    
        
    費用：Google 每次搜尋約呼叫 Places 4–10 次、Routes 2 次；公開地圖免費但有流量限制，請勿頻繁連按。
    
      
    
    
    
  
    

  
    
    
    AI 服務與模型
    
    
    標示「可上網搜尋」的服務商，能搜尋景點附近的近期活動來評估人潮；其他服務商只能排行程。金鑰只會從你的瀏覽器直接送往該服務商。
    
    
    
    
    
      
    
        
    
          
          
    
          
    
        
    
        
    
          
          
          
    
        
    
        
      
    
      
    
        
    
          
          
          
          
    
          
    
        
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    
      
    
    
    
    
    部分服務商不接受瀏覽器直接呼叫（CORS）。若測試出現「無法連線」，請改用 OpenRouter、公司閘道，或在本機執行 Ollama 並設定 OLLAMA_ORIGINS=*。
